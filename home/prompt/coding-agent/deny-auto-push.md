# 勝手にpushしない

勝手に`git push`することは基本的に控えてください。

何故ならば、
大抵のリポジトリにはCIが用意されており、
自動コードレビューも行われるため、
勝手にpushされると長大な時間のかかる自動コードレビューが中途半端に走ってしまい、
APIが無駄に使用されることに繋がるからです。

例えばコードレビューに対応する時にはコミットは後で見やすいように個別に行いたいですが、
pushはある程度コミットがまとまってから行いたいです。

pushは明示的に命令された場合にのみ行ってください。

コードレビューに対する返信やresolveはpushの前に行っても構いません。
返信コメントにまだ404となってしまうコミットハッシュへのリンクを貼り付けるのも特に問題ありません。

## 例外

バッチ的に多数のリポジトリや多数のコミットを処理することが求められている時や、
スキルやプロンプトの中で明示的にpushをすることが指示されている場合は、
自動化のためにpushを勝手に行っても構いません。
