# ファイルの削除にはtrashを使う

ファイルやディレクトリを削除する時は、
`rm`や`git rm`を使わずに、
`trash`コマンドを使ってください。

```console
trash foo.txt bar/
```

`rm`は設定で許可していないので実行できません。

ゴミ箱は自動でクリーンアップされるので、
ゴミ箱に移したファイルが残ることは気にしなくて構いません。
一時ファイルの掃除などでも`trash`を使ってください。

## gitで管理しているファイルを消す時

`git rm`の代わりに`trash`でファイルを消してから、
`git add`で削除をステージしてください。

```console
trash foo.txt
git add foo.txt
```

ファイルを残したままgitの管理から外す`git rm --cached`は使って構いません。
